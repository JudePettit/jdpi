        Sources. The datasets are PRP's own published data, listed in the Integration Hub's catalogue (integration/catalog.json, date to follow); each dataset names its own sources and licence above, and they apply to anything you export from it.
        
    
        Method. Files load straight from this site into your browser and every step runs there: filters, expression filters and derived columns (a small expression language, never run as code), one row per list item, grouping with count, sum, mean, median, minimum, maximum and distinct values, sorting and limits. On dates a filter value is a period: 2026 is the whole year. Nested objects are spread into dotted columns (place.lat). Charts follow PRP's style: categorical colours in a fixed order, at most eight series (three on scatter plots) with the rest grouped as “Other”, and a table for every chart. Maps match ISO codes and English country names to Natural Earth borders (world-atlas, 1:110m).
        
    
        Limits. The page asks before loading more than 20 MB and will not load more than 120 MB; for larger data use the Integration Hub's API or MCP server, which query in parts. SQL is optional and runs locally in DuckDB.
        
    
        Libraries. Observable Plot 0.6.17 and d3 7.9.0 (ISC licence), topojson-client 3.1.0 and world-atlas 2.0.2, and DuckDB-WASM 1.32.0 (MIT) with Apache Arrow 17.0.0 (Apache 2.0) when you use SQL, all pinned on jsDelivr and loaded only when needed.
