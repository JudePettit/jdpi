How the index works

Data. GDELT 2.0 event exports, all 96 quarter-hour files a day, which code news reports worldwide into who-did-what-to-whom events (CAMEO) with a location and a Goldstein score; the index is rebuilt every morning. The GDELT Project ↗

Context. Regions, government, political stability (World Bank Worldwide Governance Indicators) and battle deaths in active wars (UCDP, via Realtime Battlefield) come from National Analysis.

Map. Natural Earth 1:110m boundaries via world-atlas. Caveat. The GVI measures news coverage, not events on the ground; see the Method tab.
