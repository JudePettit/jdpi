Integration Hub

PRP's data, open to AI assistants and plugins: a catalogue of every dataset, a read-only MCP server, a JSON API, feeds and calendars. Everything is public and read-only, and needs no key.

What PRP offers an AI assistant

PRP collects what is happening in the world, and what happened before, into one workspace: elections and political events, wars and armed conflict, each country's condition and volatility, a century of political history, the news across the political spectrum, new research in science, economics and technology, disclosures by members of Congress and famous investors, and an Encyclopaedia that links them all.

The Integration Hub lets an assistant such as Claude read all of it directly, so it can answer with PRP's figures and say where each came from. It can list the datasets, look at their fields, filter and sort rows, search the Encyclopaedia, read the latest briefings, check the political calendar and pull together one country's picture.

Nothing can be changed through it, nothing private is in it, and there is nothing to sign up for.

Connect

Remote · Streamable HTTP

The server address is https://jdpi.pages.dev/mcp. It needs no key or sign-in.

Claude Code

claude mcp add --transport http prp https://jdpi.pages.dev/mcp

Claude (desktop and web)

Open Settings → Connectors → Add custom connector, name it PRP and paste the server address. Leave the authentication settings empty.

Other MCP clients

Any client that speaks MCP over Streamable HTTP can use the address directly. A client that only runs local (stdio) servers can use the local server below, or a bridge such as mcp-remote.

{
  "mcpServers": {
    "prp": { "type": "http", "url": "https://jdpi.pages.dev/mcp" }
  }
}

Run it locally

stdio · Node 18+

The same tools as one file with no dependencies. It reads PRP's files over HTTPS and has no edge time limit, so it can read every shard of a big dataset in one call.

Download prp-mcp.mjs

Claude Code

claude mcp add prp-local -- node /path/to/prp-mcp.mjs

Claude Desktop (claude_desktop_config.json)

{
  "mcpServers": {
    "prp": { "command": "node", "args": ["/path/to/prp-mcp.mjs"] }
  }
}

Options: --base <url> to read another copy of the site, --max-rows, --tools to list the tools, --call <tool> '<json>' to run one from a terminal, --help.

Filtering rows

        

          
Add f.<field>=<value> for equality, or f.<field>.<op>=<value> with an op: ne, gt, gte, lt, lte, contains, starts_with, in (comma-separated) or exists. Text matches ignore case and accents. Then select=a,b, sort=-date, limit (up to 100), offset and text for words anywhere in a row.

          
curl "https://jdpi.pages.dev/api/v1/datasets/congress-trades/rows?f.ticker=NVDA&select=filed,name,type,amount&limit=10"

          
Big datasets are split into shards, read newest first within a time budget. If a result says "complete": false, narrow it by date or by the field it names, or pass its next_cursor as cursor.

        

      

      

        
From a browser or a script

        

          
Responses carry Access-Control-Allow-Origin: *, so any web page can read them.

          
const res = await fetch('https://jdpi.pages.dev/api/v1/events?country=France&type=election');
const { events } = await res.json();
for (const e of events) console.log(e.date, e.title);

          
Errors are JSON too: {"error": {"code", "message"}} with status 400, 404, 405 or 429. The static files listed in the catalogue need no API at all.

    The PRP skill for Claude
    
        
    
          
    A skill teaches Claude when and how to use PRP's data: which tool answers which question, how to query well, what each dataset's caveats are and how to credit sources. It works with the MCP server connected, or with plain web access through the API.
    
          
    Download prp-data.zip Read SKILL.md
    
          
    Claude (desktop and web)
    
          
    Settings → Capabilities → Skills → Upload skill, then choose the zip.
    
          
    Claude Code
    
          
    mkdir -p ~/.claude/skills && cd ~/.claude/skills \
  && curl -fsSLO https://jdpi.pages.dev/integration/skill/prp-data.zip \
  && unzip -o prp-data.zip && rm prp-data.zip
    
          
    Any other assistant
    
          
    Point it at /llms.txt, a short guide for language models: what PRP is, where the catalogue, MCP server and API are, and the licences.
    
        
    
      
    
      
    
        
    For plugin authors
    
        
    
          
    Build on the catalogue. catalog.json is the contract: dataset ids, file paths, record paths and field names stay stable, and new fields are only added. Read it rather than hard-coding file names.
    
          
    Bundle the server. A Claude Code plugin can declare PRP in its .mcp.json (either the remote address or the local file) and ship the skill in its skills/ folder.
    
          
    {
  "mcpServers": {
    "prp": { "type": "http", "url": "https://jdpi.pages.dev/mcp" }
  }
}
    
          
    Be a good neighbour. Cache what you read (most data change daily or less), keep to about two requests a second, and for bulk work download the static files once. Show the licence and sources the catalogue gives, and link back to the PRP page (page) where people can see the data in context.
    
          
    Versioning. The API lives under /api/v1/; a breaking change would come as /api/v2/, with v1 kept running.
    
        
    
      
    
    
    
  
    

  
  
    
    
    
      
    
        
    What it can and cannot do
    
        
    
          
      
            
    • Read-only. Every tool and endpoint only reads; none accepts data to store, and none changes anything in PRP.
      • 
            
    • Public data only. It serves the same files as PRP's public pages. There are no accounts, cookies or keys, and it keeps nothing about you beyond a one-minute request count used for rate limiting.
      • 
            
    • Fixed files. The server reads only the files the catalogue lists (plus the Encyclopaedia shards and country profiles). A tool argument can never name a file, and nothing is fetched from anywhere else.
      • 
            
    • Capped. At most 100 rows and about 48 KB per answer; long texts are shortened; a search uses at most eight words; big datasets are read in shards within a work budget. Every answer says when it was cut.
      • 
            
    • Rate-limited. About 120 MCP calls and 240 API calls a minute per client, and one tool call per request (a batch included). Over that you get 429 with Retry-After. For heavy use, run the local server or download the files.
      • 
          
    
        
    
      
    
      
    
        
    What is never exposed
    
        
    
          
    Tally Stick and Algo Trader, PRP's private trading tools, are not part of the Integration Hub. There are no balances, positions, orders, brokers, rules, risk limits or keys here. Tally Stick's own MCP connection for trading agents is a separate, private server behind its own sign-in; this server cannot reach it and shares nothing with it.
    
          
    Nothing personal. Your topics in the Intelligence Briefing, your OSINT case notebook and other things you keep in PRP pages stay in your browser and never reach these servers.
    
          
    Text is data, not instructions
    
          
    Headlines, summaries and notes come from publishers, Wikipedia and Wikidata. The server returns them as data fields and tells assistants not to follow instructions found inside them. If you build on PRP, do the same.
