# Data Analytics (Digital Science)

A workbench for Vitruvian Manager's own data: pick a dataset from the Integration Hub's catalogue, transform it, chart it, export it,
or copy the analysis for an AI assistant. Everything runs in the browser; the page stores no keys and calls no AI service.

## Files

| File | What it does |
|---|---|
| `index.html`, `analytics.css`, `app.js` | The page: dataset list, dataset card, steps (or SQL), result table, chart, exports, Copy for AI, Catalogue tab |
| `lib/engine.js` | Transform engine over `{ columns: [{ name, type }], rows }`: filter, expression filter, columns, derive, one row per list item, group (count, sum, mean, median, min, max, distinct), sort, limit; type inference; CSV |
| `lib/expr.js` | The expression language for derived columns and expression filters. Parsed into a tree and evaluated; never `eval` or `new Function` |
| `lib/spec.js` | The analysis as a plain object, its URL hash (below) and its description in words |
| `lib/chartdata.js` | What each chart draws (aggregation, "Other" folding, histogram bins, country matching) and its table view; chart suggestions |
| `lib/render.js` | Draws with Observable Plot 0.6.17 and d3 7.9.0 (jsDelivr, SRI), loaded on the first chart; world map from world-atlas 2.0.2 |
| `lib/export.js` | Chart as standalone SVG or PNG, with title, legend, caption and source |
| `lib/sql.js` | Optional SQL: DuckDB-WASM 1.32.0 and Apache Arrow 17.0.0 from jsDelivr, loaded on the first query |
| `lib/ai.js` | The "Copy for AI" prompt and the matching `query_dataset` call for the Integration Hub's MCP server |
| `lib/load.js` | Loading a catalogue dataset (one file or `urls` shards) with progress; asks above 20 MB, refuses above 120 MB |
| `lib/examples.js` | Starting points on the empty page (each is tested against the real data) |
| `lib/countries.js` | ISO codes and names for maps; generated by `scripts/build-countries.mjs` from National Analysis |
| `test-fixtures/` | A small catalogue in the Hub's schema, for tests: `?catalog=analytics/test-fixtures/catalog.json` |

Tests: `node --test tests/data-analytics.test.mjs` (page tests use `JDPI_URL`, default `http://localhost:8787`).

## The analysis in the address

The hash holds the dataset, the steps in order, an SQL query (instead of steps) and the chart, so a link reopens the
same analysis. Names and values are percent-encoded, including `! ' ( ) * ~`, so `:`, `,`, `~` and a leading `-` are
always structure; expressions and SQL keep `( ) * ' ~ !` readable.

```
#d=<dataset id>
&filter=<column>:<eq|ne|gt|ge|lt|le|contains|starts|in|empty|notempty>[:<value>]     in: a | b | c
&where=<expression>
&select=<column>,<column>
&derive=<new column>:<expression>
&unnest=<list column>
&group=<column>,<column>:<count|sum|mean|median|min|max|distinct>[~<column>[~<new name>]],…
&sort=<column>,-<column>          (- for descending)
&limit=<n>
&sql=<query over the table data>
&chart=<bar|line|area|scatter|hist|map>&x=<column>&y=<column>&fn=<sum|mean|median|min|max>&color=<column>&bins=<n>
&tab=catalogue
```

Example: `#d=political-calendar&filter=type:eq:election&derive=year:year(date)&group=year:count&chart=line&x=year&y=count`.

On dates a filter value is a period: `date:eq:2026` is the whole year, `date:gt:2026-06` is from July 2026.

A link is anyone's to write, so the page treats it as data and bounds what it can ask for: at most 60 steps are read;
an expression is at most 600 characters, a text value it makes at most 10,000, and the expressions of one run of the
steps make at most 50 million characters of text; one row per list item makes at most 500,000 rows. Past a limit the
step stops with the reason and is skipped. Dataset files load only from this site. In "Copy for AI", text from the link
and the data stays on one line each and the prompt tells the assistant it is data, not instructions.

## Charts

PRP-STYLE §6: categorical tokens `--prp-cat-1…8` in fixed order (series named alphabetically, so a series keeps its
colour); more than eight series keep seven colours and fold the rest into a neutral "Other"; scatter plots keep three.
Sequential tokens for maps. Grid `--prp-grid`, axes `--prp-axis`, text in text tokens. Every chart has a table view, a
numbered caption with its source and licence, tooltips, and redraws on `prp:themechange`.
